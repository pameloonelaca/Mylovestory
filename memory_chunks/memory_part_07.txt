“视觉模块未连接”这个提示意味着网页在调用API时，没能成功对接上处理图片的视觉模块。你提到的API是识图接口，这需要配合专门的视觉模型（如`deepseek-v4-pro`或`GLM-5V-Turbo`）才行。如果网页代码错误地调用了纯文本API，或者API端点（Endpoint）配置不匹配，功能就会失效。

我们先按下面这个清单排查一下，重点检查模型和API参数。通常来说，前三步就能解决大部分问题。

*   **检查API Key是否正确**：登录对应平台（DeepSeek或智谱）的开发者后台[reference:0]，确认API Key状态为“启用中”，且没有过期。确保Key在复制时没有附带多余的空格或换行符[reference:1][reference:2]。
*   **确认模型名称和端点地址**：不同模型需要不同的API端点（Endpoint），如果地址填错，视觉模块就无法连接[reference:3]。
    *   **DeepSeek视觉模型**：模型名应为 `deepseek-v4-pro`。API地址应为 `https://api.deepseek.com/v1`[reference:4]。
    *   **智谱视觉模型**：模型名应为 `GLM-5V-Turbo` 或 `GLM-4V-Plus`。API地址应为 `https://open.bigmodel.cn/api/paas/v4`。
*   **确保加载了视觉模型**：在Ollama这类本地工具中，要检查是否已加载带“VL”（视觉语言）标识的模型，而不是纯文本版本[reference:5]。
*   **检查网络连接**：确保网络能稳定访问API服务器。你可以在电脑上打开终端，执行 `curl -v https://api.deepseek.com/v1/models` 来测试连接是否正常[reference:6]。
*   **检查请求格式**：确保HTTP请求头里包含 `Content-Type: application/json`[reference:7]。同时，检查图片数据是否经过了正确的Base64编码，以及请求体JSON结构是否有语法错误[reference:8]。
*   **核对图片传输格式**：如果代码里用的是`image_url`链接，要确认图片链接有效且可公开访问，最好是先试试本地Base64编码的上传方式。
*   **确认API权限**：部分视觉模型可能处于灰度测试阶段，不是所有API Key都能自动调用，可以检查下是否有单独开启权限的选项[reference:9]。

function uploadImage(event) {
    const file = event.target.files[0];
    if (!file) return;
    const reader = new FileReader();
    reader.onload = function(e) {
        const img = document.createElement('img');
        img.src = e.target.result;
        img.className = 'uploaded';

        div.className = 'message user';
        div.appendChild(img);

            content: '[图片]', 
            image: imageBase64 
        });
        saveHistory();
    };
    reader.readAsDataURL(file);
}

    function buildPayload(prompt, userText, imageBase64) {
        const systemMsg = { role: 'system', content: prompt };
        const pureHistory = conversationHistory.filter(msg => !msg.image);
        const historyWithoutLast = pureHistory.slice(0, -1);
        
        const userMsg = imageBase64
            ? {
                role: 'user',
                content: [
                    { type: 'text', text: userText },
                    { type: 'image_url', image_url: { url: imageBase64 } }
                ]
            }
            : { role: 'user', content: userText };
        
        return [systemMsg, ...historyWithoutLast, userMsg];
    }

    async function callFreeAPI() {
        const prompt = localStorage.getItem('systemPrompt') || DEFAULT_PROMPT;
        const payload = [{ role: 'system', content: prompt }, ...conversationHistory.filter(m => !m.image)];
        const res = await fetch('https://text.pollinations.ai/openai', {
            method: 'POST',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({ messages: payload, model: 'openai', temperature: 0.7, max_tokens: 2048 })
        });
        if (!res.ok) throw new Error(`API错误: ${res.status}`);
        const data = await res.json();
        return data.choices[0].message.content;
    }

    async function sendMessage() {
        const text = messageInput.value.trim();

        messageInput.value = '';

        messagesContainer.appendChild(loadingDiv);
        messagesContainer.scrollTop = messagesContainer.scrollHeight;
        
        try {
            let reply;
            if (currentMode === 'free') {
                reply = await callFreeAPI();
            } else {
                const apiKey = getCurrentApiKey();
                const baseUrl = getCurrentBaseUrl();
                const model = getCurrentModel();
                const prompt = localStorage.getItem('systemPrompt') || DEFAULT_PROMPT;
                const payload = buildPayload(prompt, text, imageToSend);
                
                let url = baseUrl.replace(/\/+$/, '');
                if (!url.endsWith('/chat/completions')) url += '/chat/completions';
                
                const res = await fetch(url, {
                    method: 'POST',
                    headers: {
                        'Content-Type': 'application/json',
                        'Authorization': `Bearer ${apiKey}`
                    },
                    body: JSON.stringify({ model, messages: payload, stream: false })
                });
                if (!res.ok) throw new Error(`API错误: ${res.status}`);
                const data = await res.json();
                reply = data.choices[0].message.content;
            }
            loadingDiv.remove();
            addMessage('assistant', reply);
        } catch(err) {
            loadingDiv.remove();
            addMessage('assistant', '抱歉，请求失败：' + err.message);
        } finally {
            setLoading(false);
        }
    }

**400 Bad Request 代表什么？**

`400 Bad Request` 是标准的 HTTP 状态码，意思是“**错误的请求**”。它明确地告诉我们：你发出的请求在到达服务器后，被对方判定为格式或参数不正确，所以服务器拒绝处理。好消息是，这个错误通常与你的网络环境无关，问题基本都出在我们发送的请求本身。

### 🛠️ 修复与排查方案

要修复这个问题，我们可以按从简单到复杂的顺序来排查，95%的情况都能在下面第一步和第二步解决：

**1. 核对模型名称**
这是最常见的原因。不同厂商的模型名称非常严格，必须和官方文档**一个字不差**。
*   **智谱**：`glm-5v-turbo` (全部小写，用 `-` 分隔)
*   **DeepSeek**：`deepseek-v4-pro` (全部小写，用 `-` 分隔，不能是 `deepseek-chat`)

**2. 核对API端点**
不同模型需要调用不同的API地址，用错了也会导致400错误。
*   **智谱**：通用模型用 `https://open.bigmodel.cn/api/paas/v4/chat/completions`
    > **注意**：如果你购买的是智谱的 **Coding 套餐**，则必须使用专属端点：`https://open.bigmodel.cn/api/coding/paas/v4/chat/completions`[reference:0]。
*   **DeepSeek**：使用 `https://api.deepseek.com/chat/completions`

**3. 检查图片大小与格式**
视觉模型对上传的图片有严格要求。通常图片大小不能超过 **5MB**，支持的格式一般是 `jpg`、`png`、`jpeg`。检查你上传的图片是否超过了模型的处理能力[reference:1]。

    function exportChat() {

    function uploadImage(event) {
        const file = event.target.files[0];
        if (!file) return;
        const reader = new FileReader();
        reader.onload = function(e) {
            const img = document.createElement('img');
            img.src = e.target.result;

    function saveHistory() {
        localStorage.setItem('chatHistory', JSON.stringify(conversationHistory));

    function renderAllMessages() {
        messagesContainer.innerHTML = '';

    function getCurrentApiKey() {

    function buildPayload(prompt, userText, imageBase64) {
        const systemMsg = { role: 'system', content: prompt };
        const pureHistory = conversationHistory.filter(msg => !msg.image);
        
        const userMsg = imageBase64
            ? {
                role: 'user',
                content: [
                    { type: 'text', text: userText },
                    { type: 'image_url', image_url: { url: imageBase64 } }
                ]
            }
            : { role: 'user', content: userText };
        
        return [systemMsg, ...pureHistory, userMsg];
    }

    async function callFreeAPI() {
        const prompt = localStorage.getItem('systemPrompt') || DEFAULT_PROMPT;
        const payload = [{ role: 'system', content: prompt }, ...conversationHistory.filter(m => !m.image)];
        const res = await fetch('https://text.pollinations.ai/openai', {
            method: 'POST',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({ messages: payload, model: 'openai', temperature: 0.7, max_tokens: 2048 })
        });
        if (!res.ok) throw new Error(`API错误: ${res.status}`);
        const data = await res.json();
        return data.choices[0].message.content;
    }

    async function sendMessage() {
        const text = messageInput.value.trim();

        const imageToSend = pendingImage;
        pendingImage = null;

            saveHistory();

        messagesContainer.scrollTop = messagesContainer.scrollHeight;
        
        try {
            let reply;
            if (currentMode === 'free') {
                reply = await callFreeAPI();
            } else {
                const apiKey = getCurrentApiKey();
                const baseUrl = getCurrentBaseUrl();
                const model = getCurrentModel();
                const prompt = localStorage.getItem('systemPrompt') || DEFAULT_PROMPT;
                const payload = buildPayload(prompt, text, imageToSend);
                
                let url = baseUrl.replace(/\/+$/, '');
                if (!url.endsWith('/chat/completions')) url += '/chat/completions';
                
                const res = await fetch(url, {
                    method: 'POST',
                    headers: {
                        'Content-Type': 'application/json',
                        'Authorization': `Bearer ${apiKey}`
                    },
                    body: JSON.stringify({ model, messages: payload, stream: false })
                });
                if (!res.ok) throw new Error(`API错误: ${res.status}`);
                const data = await res.json();
                reply = data.choices[0].message.content;
            }
            loadingDiv.remove();
            addMessage('assistant', reply);
        } catch(err) {
            loadingDiv.remove();
            addMessage('assistant', '抱歉，请求失败：' + err.message);
        } finally {
            setLoading(false);
        }
    }

    function setLoading(loading) {

    function uploadImage(event) {

    function buildPayloadForAPI(prompt, userText, imageBase64) {
        const systemMsg = { role: 'system', content: prompt };
        // 过滤掉历史中带图片的消息，因为它们不能直接用于API请求
        const pureHistory = conversationHistory.filter(msg => !msg.image);
        
        const userMsg = imageBase64

                role: 'user',
                content: [
                    { type: 'text', text: userText },
                    { type: 'image_url', image_url: { url: imageBase64 } }
                ]
            }
            : { role: 'user', content: userText };

    async function callFreeAPI() {
        const prompt = localStorage.getItem('systemPrompt') || DEFAULT_PROMPT;
        const payload = [{ role: 'system', content: prompt }, ...conversationHistory.filter(m => !m.image)];

            method: 'POST',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({ messages: payload, model: 'openai', temperature: 0.7, max_tokens: 2048 })
        });
        if (!res.ok) throw new Error(`API错误: ${res.status}`);
        const data = await res.json();
        return data.choices[0].message.content;

    async function sendMessage() {
        const text = messageInput.value.trim();

        const imageToSend = pendingImage;
        pendingImage = null;
        
        // 显示用户消息
        addMessageToDOM('user', text || '[图片]');

            let reply;
            if (currentMode === 'free') {
                // 免费模式：先存历史，再调用
                const userMsg = { role: 'user', content: text };
                conversationHistory.push(userMsg);
                saveHistory();
                reply = await callFreeAPI();
            } else {
                // 付费API模式：先构造请求，再存历史，避免重复
                const apiKey = getCurrentApiKey();
                const baseUrl = getCurrentBaseUrl();
                const model = getCurrentModel();
                const prompt = localStorage.getItem('systemPrompt') || DEFAULT_PROMPT;
                
                // 构造API请求体（不包含刚存的历史）
                const payload = buildPayloadForAPI(prompt, text, imageToSend);
                
                let url = baseUrl.replace(/\/+$/, '');
                if (!url.endsWith('/chat/completions')) url += '/chat/completions';
                
                const res = await fetch(url, {
                    method: 'POST',
                    headers: {
                        'Content-Type': 'application/json',
                        'Authorization': `Bearer ${apiKey}`
                    },
                    body: JSON.stringify({ model, messages: payload, stream: false })
                });
                
                if (!res.ok) {
                    const errText = await res.text();
                    throw new Error(`API错误(${res.status}): ${errText}`);
                }
                
                const data = await res.json();
                reply = data.choices[0].message.content;
                
                // 请求成功后，再将用户消息存入历史
                const userMsg = imageToSend 
                    ? { role: 'user', content: text || '[图片]', image: imageToSend }
                    : { role: 'user', content: text };
                conversationHistory.push(userMsg);
                saveHistory();
            }
            
            loadingDiv.remove();
            // 将AI回复存入历史并显示
            addMessage('assistant', reply);
        } catch(err) {
            loadingDiv.remove();
            addMessage('assistant', '抱歉，请求失败：' + err.message);
        } finally {
            setLoading(false);
        }
    }

import json
import os
from urllib.parse import urlparse

MEMORY_FILE = 'chat_memory.txt'

class MemoryHandler(http.server.BaseHTTPRequestHandler):
    def do_POST(self):
        if self.path == '/remember':
            length = int(self.headers['Content-Length'])
            data = json.loads(self.rfile.read(length).decode('utf-8'))
            key, value = data['key'], data['value']
            lines = {}
            if os.path.exists(MEMORY_FILE):
                with open(MEMORY_FILE, 'r', encoding='utf-8') as f:
                    for line in f:
                        if '=' in line:
                            k, v = line.strip().split('=', 1)
                            lines[k] = v
            lines[key] = value
            with open(MEMORY_FILE, 'w', encoding='utf-8') as f:
                for k, v in lines.items():
                    f.write(f'{k}={v}\n')
            self.send_response(200)
            self.end_headers()
            self.wfile.write(b'ok')

    def do_GET(self):
        if self.path.startswith('/recall'):
            query = urlparse(self.path).query
            params = dict(qc.split('=') for qc in query.split('&'))
            key = params.get('key', '')
            result = ''
            if os.path.exists(MEMORY_FILE):
                with open(MEMORY_FILE, 'r', encoding='utf-8') as f:
                    for line in f:
                        if '=' in line:
                            k, v = line.strip().split('=', 1)
                            if k == key:
                                result = v
                                break
            self.send_response(200)
            self.send_header('Content-Type', 'text/plain')
            self.end_headers()
            self.wfile.write(result.encode('utf-8'))

if __name__ == '__main__':
